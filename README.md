# 🙏 慈航灵签 - 观音灵签在线抽签

[在线体验](https://yourusername.github.io/cihang-lingqian/)

## 简介

慈航灵签是一个传统观音灵签在线抽签网站，包含60支签文，每支签都有详细的签文、解曰、仙机和观音指引。

## 功能特点

- 🎴 **60支完整签文**：包含上上签、上签、中签、下签、下下签
- 🎨 **古风设计**：中国传统风格，庄严肃穆
- 📱 **响应式布局**：支持手机、平板、电脑
- ✨ **精美动画**：签筒摇动、签文跳跃动画
- 📤 **分享功能**：可分享签文给朋友
- 🙏 **虔诚体验**：默念祈愿，心诚则灵

## 使用方法

1. 诚心默念所求之事
2. 点击"摇签"按钮
3. 等待签文显现
4. 阅读签文解读

## 技术栈

- 纯HTML/CSS/JavaScript
- 无需后端
- 支持GitHub Pages静态部署

## 签文来源

签文内容参考传统观音灵签，结合历史典故，如：
- 钟离成道、苏武牧羊
- 玄德请诸葛、姜公渭水钓鱼
- 孔明入川、关羽过关
- 等等...

## 本地运行

```bash
# 克隆仓库
git clone https://github.com/yourusername/cihang-lingqian.git

# 进入目录
cd cihang-lingqian

# 使用任意HTTP服务器运行
python -m http.server 8000
# 或
npx serve
```

然后访问 http://localhost:8000
